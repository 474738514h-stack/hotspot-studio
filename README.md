# 热点营销工作台

电商媒体运营用的热点营销原型。从新闻抓取、商品匹配，到微博文案生成、合规审核和模拟发布，五步在同一个工作台里走完。

当前新闻、商品和文案都是**样本数据**。文案由本地演示引擎生成，不会请求外部大模型。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3847`。

## 怎么用

1. 在「新闻抓取」里点一条热点。标成禁止借势的时政、军事和公共安全新闻不能进入文案。
2. 「建议匹配商品」按匹配度给出商品，也可以在「匹配商品」里搜索后手动绑定，最多 3 件。
3. 「创作文案」选择语气、篇幅和表情，点生成。大约 1.5 秒后给出 3 条可编辑、可复制的微博正文。
4. 「审核并发送」查看微博卡片和合规结果。通过后可以模拟发布，不会调用微博接口。

顶部可以在手工模式和自动模式之间切换。自动模式会在选定可借势热点后采纳商品并生成文案，发布前仍需人工审核。

个人中心里有演示账号「运营小童 · Yuki」的注册信息。清单和后台管理可以查看本轮进度、热点源和禁用词。

## 接入真实模型

界面只调用 `src/lib/copy/engine.ts`。后续把 `src/lib/copy/llm-adapter.ts` 里的 `buildLlmRequest` 交给服务端即可：

- `LLM_API_BASE`
- `LLM_API_KEY`
- `LLM_MODEL`

同一份输入也可以交给 Coze 工作流。未配置这些变量时，工作台继续使用本地演示引擎。
